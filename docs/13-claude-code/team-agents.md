# AI 팀을 만들어서 일 시키기

> 혼자 코딩하지 마세요. AI 팀원 여러 명에게 동시에 일을 시킬 수 있어요!

---

## 🤖 에이전트가 뭔지

**에이전트(Agent)**는 독립적으로 작업을 수행하는 AI 비서예요.

일반 대화와 다른 점:

| | 일반 대화 | 에이전트 |
|---|-----------|----------|
| 작업 방식 | 한 번에 하나씩 | 여러 개 동시에 |
| 자율성 | 매번 확인받음 | 계획 세우고 자동 실행 |
| 적합한 작업 | 간단한 수정 | 복잡한 기능 구현 |

### 비유하면

```
일반 대화 = 옆에서 지시하며 같이 일하기
에이전트 = "이거 해놔" 하고 맡겨두기
```

---

## 1단계: 에이전트 사용해보기

Claude Code에서 이렇게 말해보세요:

```
"에이전트 모드로 FAQ 페이지 만들어줘"
```

에이전트가 알아서:

1. 기존 프로젝트 구조를 분석하고
2. 필요한 파일들을 파악하고
3. 코드를 작성하고
4. 완성된 결과를 보여줘요

> 💡 **팁**: 복잡한 작업일수록 에이전트 모드가 효율적이에요.

---

## 2단계: 팀 만들기

Claude Code에는 **팀 에이전트** 기능이 있어요. 여러 AI 에이전트에게 서로 다른 일을 **동시에** 시킬 수 있어요.

### 팀 구성 예시

```
Team Lead (리더) ─── Frontend Agent (프론트엔드)
                ├── Backend Agent (백엔드)
                └── Test Agent (테스트)
```

### 사용 방법

Claude Code에서:

```
"팀을 만들어서 작업해줘:
- 프론트엔드: 랜딩 페이지 리디자인
- 백엔드: API 라우트 추가
- 테스트: 기능 테스트 작성"
```

리더 에이전트가 자동으로:

1. 팀원별 작업을 분배하고
2. 각 에이전트가 동시에 작업하고
3. 결과를 통합해줘요

---

## 3단계: 실전 - 여러 에이전트에게 동시에 일 시키기

### 예시 1: 신기능 추가

```
"팀으로 작업해줘:
1. 블로그 목록 페이지 만들기
2. 블로그 상세 페이지 만들기
3. 블로그 데이터 API 만들기"
```

### 예시 2: 버그 수정 + 기능 개선

```
"동시에 처리해줘:
1. 모바일에서 메뉴가 안 열리는 버그 수정
2. 다크 모드 색상 개선
3. 로딩 속도 최적화"
```

### 예시 3: 이 프로젝트에서의 실제 활용

```
"팀으로 이 작업들 동시에 해줘:
1. HeroSection 애니메이션 개선
2. PricingSection 가격 변경
3. 한국어 번역 파일 업데이트"
```

---

## 4단계: 태스크(Task) 시스템 이해하기

팀 에이전트는 **태스크 시스템**으로 작업을 관리해요.

### 태스크 상태

```
pending (대기) → in_progress (진행 중) → completed (완료)
```

### 작업 흐름

```
1. 리더가 태스크 생성
2. 팀원에게 할당
3. 팀원이 작업 시작 (in_progress)
4. 완료되면 리더에게 보고 (completed)
5. 리더가 다음 태스크 할당
```

### 의존성 설정

어떤 작업은 다른 작업이 끝나야 시작할 수 있어요:

```
"데이터베이스 스키마 먼저 만들고, 그 다음에 API를 만들어줘"
```

이렇게 말하면 AI가 자동으로 순서를 관리해줘요.

---

## 💡 팀 에이전트 활용 팁

### 잘 되는 경우

- 서로 독립적인 작업을 동시에 할 때
- 프론트엔드 + 백엔드를 나눠서 할 때
- 코드 작성 + 테스트를 병렬로 할 때

### 주의할 점

- 같은 파일을 여러 에이전트가 동시에 수정하면 충돌이 날 수 있어요
- 작업을 너무 잘게 나누면 오히려 비효율적이에요
- 3~5개 정도의 에이전트가 적당해요
