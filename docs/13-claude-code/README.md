# Claude Code로 바이브 코딩 시작하기

> 코딩을 몰라도 AI에게 말로 프로그래밍하는 "바이브 코딩"을 시작해보세요!

---

## 🤔 바이브 코딩이란?

**바이브 코딩(Vibe Coding)**은 코드를 직접 작성하지 않고, AI에게 **자연어(한국어)로 지시**해서 프로그래밍하는 방식이에요.

예를 들어:
- "로그인 페이지 만들어줘"
- "이 버튼 색상 빨간색으로 바꿔줘"
- "결제 기능 추가해줘"

이렇게 말만 하면 AI가 코드를 작성하고, 파일을 수정하고, 심지어 배포까지 도와줘요.

> 💡 **핵심 포인트**: 코딩 경험이 전혀 없어도 괜찮아요. 한국어로 말하면 돼요!

---

## 1단계: Claude Code 설치하기

### Mac 사용자 (권장: 네이티브 설치)

터미널(Terminal)을 열고 아래 명령어를 입력해요:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

> 💡 **터미널 여는 법**: `Cmd + Space` → "터미널" 검색 → 엔터

이 방법으로 설치하면 **자동 업데이트**가 지원돼요!

**또는 Homebrew로 설치** (수동 업데이트):

```bash
brew install --cask claude-code
```

### Windows 사용자

PowerShell에서:

```powershell
irm https://claude.ai/install.ps1 | iex
```

> ⚠️ **주의**: Git for Windows가 먼저 설치되어 있어야 해요. [git-scm.com](https://git-scm.com) 에서 다운로드하세요.

**또는 WinGet으로 설치**:

```powershell
winget install Anthropic.ClaudeCode
```

### 설치 확인

```bash
claude --version
```

버전 번호가 출력되면 성공이에요!

---

## 2단계: 로그인하기

Claude Code를 사용하려면 Anthropic 계정이 필요해요.

처음 `claude` 명령어를 실행하면 **브라우저가 자동으로 열리면서** 로그인 화면이 나와요.

1. 브라우저에서 이메일 입력 또는 **Google로 계속** 클릭
2. 이메일 인증 (magic link) 완료
3. 터미널로 돌아오면 자동으로 연결!

> 💡 **API 키가 따로 필요 없어요!** OAuth 인증 방식이라 브라우저에서 로그인만 하면 돼요.
>
> 만약 API 키를 직접 사용하고 싶다면 [platform.claude.com](https://platform.claude.com) 에서 발급받아서 `ANTHROPIC_API_KEY` 환경변수로 설정할 수 있어요.

---

## 3단계: 첫 대화 시작하기

프로젝트 폴더에서 터미널을 열고:

```bash
claude
```

이 한마디면 Claude Code가 시작돼요!

### 기본 대화 예시

```
You: 이 프로젝트가 뭔지 설명해줘

Claude: 이 프로젝트는 Next.js 기반의 SaaS 스타터 킷이에요...

You: package.json 읽어줘

Claude: (파일을 읽고 의존성 목록을 설명해줘요)

You: 개발 서버 실행해줘

Claude: npm run dev를 실행할게요... (자동으로 실행!)
```

---

## 4단계: 파일 읽고 수정하기

Claude Code는 프로젝트의 모든 파일을 읽고 수정할 수 있어요.

### 파일 읽기

```
"src/app/page.tsx 파일 읽어줘"
"랜딩 페이지 코드 보여줘"
"환경변수 파일 확인해줘"
```

### 파일 수정하기

```
"히어로 섹션의 제목을 '10분 만에 SaaS 런칭'으로 바꿔줘"
"가격을 $49에서 $29로 변경해줘"
"이 버튼에 애니메이션 추가해줘"
```

### 파일 생성하기

```
"FAQ 컴포넌트 새로 만들어줘"
"About 페이지 추가해줘"
```

> 💡 **팁**: 수정 전에 Claude가 "이렇게 바꿔도 될까요?" 하고 물어볼 거예요. `y`를 눌러 승인하면 돼요.

---

## 5단계: 프로젝트에 질문하기

코드를 이해하지 못해도 괜찮아요! AI에게 물어보면 돼요.

### 유용한 질문들

| 질문 | 용도 |
|------|------|
| "이 프로젝트 구조 설명해줘" | 전체 구조 파악 |
| "로그인은 어떻게 구현되어 있어?" | 특정 기능 이해 |
| "이 에러 해결해줘" | 디버깅 |
| "결제 기능이 어디에 있어?" | 코드 찾기 |
| "이 컴포넌트가 하는 일이 뭐야?" | 코드 설명 |
| "비슷한 기능을 새로 만들어줘" | 기능 추가 |

## ⌨️ 자주 쓰는 명령어

| 명령어 | 설명 |
|--------|------|
| `claude` | Claude Code 시작 |
| `/help` | 도움말 보기 |
| `/clear` | 대화 초기화 |
| `/compact` | 컨텍스트 정리 (대화가 길어질 때) |
| `/cost` | 사용 비용 확인 |
| `Ctrl+C` | 현재 작업 중단 |
| `Ctrl+D` | Claude Code 종료 |
| `Esc` 2번 | 이전 지점으로 되돌리기 |
| `/exit` | Claude Code 종료 (명령어) |
