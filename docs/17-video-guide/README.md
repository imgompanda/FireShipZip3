### 보여줄 것

1. 터미널 열기 (Mac: Spotlight → Terminal)
2. `git clone` 으로 프로젝트 다운로드
3. `npm install` 실행 (패키지 설치)
4. `.env.local` 파일 생성 (환경변수)
5. `npm run dev` 실행
6. 브라우저에서 `localhost:3000` 열기
7. 랜딩페이지가 뜨는 것 확인!
8. "축하해요! 첫 번째 단계 완료!"

- [ ] 각 명령어를 천천히 타이핑 (시청자가 따라올 수 있게)
- [ ] `.env.local` 파일 내용은 화면에 크게 보여주기

| 보여줄 화면 | Supabase 대시보드 + 코드 에디터 |

### 보여줄 것

1. Supabase 사이트 접속 → 회원가입 (이미 가입했다면 스킵)
2. New Project 생성 (이름, 비밀번호, 리전=Seoul)
3. Project Settings → API Keys 복사
4. `.env.local`에 URL, anon key, service_role key 입력
5. SQL Editor 열기 → 스키마 SQL 실행
6. Authentication → Google OAuth 설정
7. Google Cloud Console에서 OAuth 클라이언트 생성
8. 테스트: 로그인 성공 확인

- [ ] 각 단계마다 "이게 뭘 하는 건지" 설명 추가
- [ ] 에러 상황 → 해결 과정도 보여주면 좋음

- **프레임**: 30fps
- **인코더**: x264 또는 GPU 인코더

### 화면 구성

```

│   ┌──────────┐                 │

│   │  (선택)  │                 │
│   └──────────┘                 │
└────────────────────────────────┘
```

### 편집 팁

1. **폰트 크기를 키워요** - 터미널 폰트는 최소 16pt, 코드는 14pt 이상

5. **키 입력 표시** - KeyCastr 같은 도구로 키보드 입력을 화면에 표시
6. **챕터 마커** - YouTube 챕터를 위해 타임스탬프를 미리 메모해요
7. **자막 추가** - CapCut의 자동 자막 기능을 활용하면 편해요

- 제목은 크고 굵게 (최대 5단어)
- 코드 화면 또는 결과물 스크린샷 배경
- 얼굴이 있으면 클릭률 상승
- 노란색/빨간색 계열 강조색 사용
