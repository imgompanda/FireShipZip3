# 이미지 생성 가이드

> AI로 이미지를 생성하고 Supabase에 자동 저장하는 방법을 알아봐요!

---

## 기본 사용법

### /ai 페이지에서 이미지 생성

1. `/ai` 페이지로 이동
2. 이미지 생성 탭 선택
3. 프롬프트 입력 (예: "파란 하늘 아래 카페")
4. 생성 버튼 클릭
5. 잠시 기다리면 이미지 완성!

---

## 1단계: 이미지 생성 옵션 이해하기

### 사용 가능한 모델

| 모델 | 해상도 | 특징 | 가격 |
|------|--------|------|------|
| `dall-e-3` | 1024x1024 | 고품질, 프롬프트 이해도 높음 | ~$0.04/장 |
| `dall-e-3` | 1024x1792 | 세로 이미지 (포스터 등) | ~$0.08/장 |
| `dall-e-3` | 1792x1024 | 가로 이미지 (배너 등) | ~$0.08/장 |

### 크기 옵션

```
1024x1024 = 정사각형 (프로필, 아이콘)
1024x1792 = 세로 (스마트폰 배경, 포스터)
1792x1024 = 가로 (블로그 헤더, 배너)
```

### 품질 옵션

| 옵션 | 설명 | 가격 |
|------|------|------|
| `standard` | 기본 품질 | $0.04 |
| `hd` | 고화질 (더 세밀한 디테일) | $0.08 |

## 2단계: 프롬프트 작성 팁

### 좋은 프롬프트의 구조

```
[스타일] + [주제] + [배경/환경] + [분위기] + [추가 디테일]
```

### 예시 비교

| 나쁜 프롬프트 | 좋은 프롬프트 |
|--------------|--------------|
| "고양이" | "수채화 스타일, 창가에 앉아 있는 주황색 고양이, 따뜻한 오후 햇살, 아늑한 분위기" |
| "도시" | "사이버펑크 스타일의 미래 도시, 네온사인, 비 오는 밤, 영화적 구도" |
| "음식" | "미니멀한 일식 플레이팅, 흰색 접시 위 연어 초밥, 위에서 촬영한 앵글, 깔끔한 배경" |

### 스타일 키워드

| 카테고리 | 키워드 |
|----------|--------|
| 아트 스타일 | 수채화, 유화, 디지털 아트, 미니멀, 플랫 디자인 |
| 사진 스타일 | 인물사진, 풍경사진, 항공사진, 매크로, 보케 |
| 분위기 | 따뜻한, 차가운, 몽환적, 다크, 밝은, 레트로 |
| 구도 | 클로즈업, 와이드샷, 위에서, 45도 앵글 |
| 조명 | 자연광, 골든아워, 네온, 스튜디오 조명 |

## 3단계: Supabase Storage 연동

생성된 이미지는 자동으로 Supabase Storage에 저장돼요.

### 저장 구조

```
ai-assets/
└── ai-generations/
    └── {사용자ID}/
        ├── image-1709123456789.png
        ├── image-1709123456790.png
        └── ...
```

### 저장된 이미지 URL 형식

```
https://[project-id].supabase.co/storage/v1/object/public/ai-assets/ai-generations/[user-id]/image-[timestamp].png
```

이 URL을 블로그, SNS 등 어디서든 사용할 수 있어요!

### ai-assets 버킷 생성하기

아직 버킷이 없다면:

1. Supabase 대시보드 → Storage
2. **New Bucket** 클릭
3. 이름: `ai-assets`
4. Public: **ON**
5. 생성 완료!

### RLS 정책 추가

```sql
-- 로그인한 사용자만 자기 폴더에 업로드
CREATE POLICY "Users upload own ai assets"
  ON storage.objects FOR INSERT
  TO authenticated
  WITH CHECK (
    bucket_id = 'ai-assets'
    AND (storage.foldername(name))[2] = auth.uid()::text
  );

-- 모든 사용자가 조회 가능 (공개)
CREATE POLICY "Public view ai assets"
  ON storage.objects FOR SELECT
  TO public
  USING (bucket_id = 'ai-assets');
```

## 💰 비용 관리

### 비용 추정

| 사용량 | 월 비용 (대략) |
|--------|---------------|
| 하루 5장 | ~$6/월 |
| 하루 20장 | ~$24/월 |
| 하루 50장 | ~$60/월 |

### 비용 절약 팁

1. **standard 품질 사용**: `hd`보다 절반 가격
2. **1024x1024 크기**: 큰 크기보다 저렴
3. **사용량 제한 설정**: OpenAI 대시보드에서 월 한도 설정

### OpenAI 사용량 한도 설정

1. [platform.openai.com/settings](https://platform.openai.com/settings) 접속
2. **Billing** → **Usage limits**
3. 월 한도 설정 (예: $10)

## 🔧 트러블슈팅

### "Image generation failed" 에러

- `OPENAI_API_KEY`가 유효한지 확인
- OpenAI 잔액이 있는지 확인
- 부적절한 프롬프트는 거부될 수 있어요

### 이미지가 저장되지 않아요

- Supabase에 `ai-assets` 버킷이 있는지 확인
- 버킷이 Public으로 설정되어 있는지 확인
- RLS 정책이 설정되어 있는지 확인

### 이미지 품질이 아쉬워요

- 프롬프트를 더 구체적으로 작성해보세요
- `quality: "hd"` 옵션 사용
- 영어 프롬프트가 한국어보다 결과가 좋은 경우가 있어요
