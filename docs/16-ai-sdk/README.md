# AI 기능 설정하기

> GPT-4o 채팅, DALL-E 이미지 생성, 영상 생성까지! API 키 하나만 넣으면 내 SaaS에 AI 기능이 추가돼요.

---

## Vercel AI SDK란?

**한 줄 설명**: AI 기능을 웹앱에 쉽게 추가할 수 있게 해주는 라이브러리예요.

좀 더 쉽게 설명하면:

OpenAI API를 직접 호출하려면 스트리밍 처리, 에러 핸들링, 상태 관리 같은 복잡한 코드를 작성해야 해요. Vercel AI SDK를 쓰면 이걸 **몇 줄의 코드**로 끝낼 수 있어요.

```
직접 구현: 100줄 이상의 코드 필요
AI SDK 사용: 10줄이면 충분
```

Vercel이 만든 오픈소스 라이브러리라서 Next.js와 궁합이 완벽해요. React 컴포넌트 안에서 AI 기능을 자연스럽게 사용할 수 있어요.

## 설정: OPENAI_API_KEY만 넣으면 됨

### 1단계: OpenAI API 키 발급하기

1. [platform.openai.com](https://platform.openai.com) 에 접속해요
2. 로그인 (또는 회원가입)
3. 왼쪽 메뉴에서 **API keys** 클릭
4. **Create new secret key** 클릭
5. 이름 입력 (예: `my-saas`) → **Create secret key**
6. 생성된 키를 **즉시 복사**해요 (다시 볼 수 없어요!)

> 키는 `sk-`로 시작하는 긴 문자열이에요. 한 번만 보여주니까 반드시 복사해두세요!

### 2단계: .env.local에 입력

```bash
OPENAI_API_KEY=sk-여기에-복사한-키를-붙여넣기
```

이 한 줄이면 **채팅**과 **이미지 생성**이 바로 동작해요!

### 3단계: 개발 서버 실행

```bash
npm run dev
```

### 4단계: 확인

브라우저에서 대시보드에 로그인 → `/ai` 페이지로 이동

> 끝! 정말 이게 전부예요.

## 3가지 AI 모드 상세 설명

이 프로젝트에서는 3가지 AI 기능을 지원해요. 대시보드의 `/ai` 페이지에서 탭으로 전환할 수 있어요.

### 모드 1: AI 채팅 (GPT-4o 기반, 실시간 스트리밍)

ChatGPT처럼 사용자가 AI와 실시간으로 대화할 수 있어요.

**특징:**
- **GPT-4o 모델** 사용 (OpenAI 최신 모델)
- **실시간 스트리밍** - 글자가 하나씩 화면에 나타나요 (타이핑 효과)
- **마크다운 렌더링** - 코드 블록, 표, 목록 등을 예쁘게 보여줘요
- **대화 맥락 유지** - 이전 대화를 기억하고 연결해서 답변해요

**사용 예시:**
```
사용자: "이 프로젝트에 대해 설명해줘"
AI: "이 프로젝트는 Next.js 기반의 SaaS 스타터 킷으로..." (실시간 스트리밍)
```

**동작 원리:**
```
사용자 메시지 입력
    ↓
/api/ai/chat API Route 호출
    ↓
Vercel AI SDK가 OpenAI API에 요청
    ↓
GPT-4o가 응답 생성 (스트리밍)
    ↓
글자 단위로 화면에 실시간 표시
```

---

### 모드 2: 이미지 생성 (DALL-E 3, 다양한 사이즈/품질 선택)

텍스트 프롬프트를 입력하면 DALL-E 3가 고품질 이미지를 생성해요.

**지원하는 옵션:**

| 옵션 | 선택지 | 설명 |
|------|--------|------|
| 사이즈 | `1024x1024` | 정사각형 (기본) |
| | `1792x1024` | 가로형 (블로그 헤더에 좋음) |
| | `1024x1792` | 세로형 (스마트폰 배경에 좋음) |
| 품질 | `standard` | 일반 품질 (빠름, 저렴) |
| | `hd` | 고화질 (세밀함, 비용 2배) |
| 스타일 | `vivid` | 생동감 있는 색상과 대비 |
| | `natural` | 자연스러운 톤 |

**사용 예시:**
```
프롬프트: "미래적인 도시의 야경, 네온사인이 빛나는 사이버펑크 스타일"
→ 사이즈: 1792x1024 (가로형)
→ 품질: hd
→ DALL-E 3가 이미지 생성
→ Supabase Storage에 자동 저장
→ 화면에 이미지 표시
```

**동작 원리:**
```
프롬프트 + 옵션 입력
    ↓
/api/ai/image API Route 호출
    ↓
OpenAI DALL-E 3 API에 요청
    ↓
이미지 생성 (10~30초 소요)
    ↓
Supabase Storage(ai-generated 버킷)에 저장
    ↓
공개 URL 반환 → 화면에 표시
```

> 15-storage 문서에서 설정한 `ai-generated` 버킷에 저장돼요!

---

### 모드 3: 영상 생성 (FAL_API_KEY 필요 - 선택사항)

텍스트 프롬프트로 짧은 영상(약 4초)을 생성할 수 있어요.

**이 기능은 선택사항이에요!** `FAL_API_KEY`가 없으면 영상 탭이 비활성화되고, 채팅과 이미지는 정상 동작해요.

**FAL API 키 발급:**

1. [fal.ai](https://fal.ai) 에 가입해요
2. Dashboard → API Keys → Create Key
3. `.env.local`에 추가:

```bash
FAL_API_KEY=fal-여기에-복사한-키를-붙여넣기
```

**사용 예시:**
```
프롬프트: "바다 위를 날아가는 드론 샷, 일몰 배경"
→ FAL API가 영상 생성 (1~2분 소요)
→ Supabase Storage에 자동 저장
→ 화면에 영상 재생
```

> 영상 생성은 이미지보다 시간이 오래 걸려요 (1~2분). 생성 중에는 진행 상태를 보여줘요.

2. 대시보드 사이드바에서 **AI** 메뉴 클릭
3. 또는 직접 URL로 이동: `http://localhost:3000/ai`

### AI 페이지 구성

| Video | FAL 영상 생성 | `FAL_API_KEY` | 선택 |

## 커스터마이징하기

AI 기능을 내 SaaS에 맞게 바꾸고 싶다면 설정 파일을 수정하면 돼요.

### 설정 파일 위치

```
src/lib/ai/config.ts
```

### 바꿀 수 있는 것들

| 설정 | 기본값 | 설명 |
|------|--------|------|
| 모델 | `gpt-4o` | 다른 모델로 변경 가능 (예: `gpt-4o-mini`) |
| 시스템 프롬프트 | 기본 assistant | AI의 성격과 역할 정의 |
| 최대 토큰 | 4096 | 응답 길이 제한 |
| 이미지 사이즈 | 1024x1024 | 기본 이미지 크기 |
| 이미지 품질 | standard | standard 또는 hd |

### 시스템 프롬프트 커스터마이징 예시

AI를 "고객 지원 봇"으로 바꾸고 싶다면:

```typescript
// src/lib/ai/config.ts
export const AI_CONFIG = {
  systemPrompt: `
    당신은 SuperApp의 친절한 고객 지원 봇입니다.
    결제, 구독, 기능 관련 질문에 답변해주세요.
    항상 한국어로 답변하고, 초보자도 이해할 수 있게 설명해주세요.
    모르는 내용은 솔직히 모른다고 말하고, support@superapp.com으로 안내해주세요.
  `,
  model: "gpt-4o",
  maxTokens: 4096,
};
```

Claude Code를 사용한다면 이렇게 요청할 수도 있어요:

```
"AI 채팅의 시스템 프롬프트를 '요리 레시피 추천 봇'으로 바꿔줘.
사용자의 재료를 듣고 레시피를 추천하도록 해줘."
```

### Vercel에도 추가 (배포 환경)

배포 환경에서도 AI 기능을 쓰려면 Vercel에도 추가해야 해요:

1. Vercel 대시보드 → 프로젝트 선택
2. Settings → Environment Variables
3. `OPENAI_API_KEY` 추가
4. (선택) `FAL_API_KEY` 추가
5. **Redeploy** 실행

## 트러블슈팅

### "Invalid API Key" 에러

- `.env.local`에 `OPENAI_API_KEY`가 정확히 입력됐는지 확인
- 키가 `sk-`로 시작하는지 확인
- 개발 서버 재시작 (`npm run dev`)

### 채팅 응답이 너무 느려요

- GPT-4o는 응답에 2~5초 정도 걸릴 수 있어요 (정상)
- 인터넷 연결 상태를 확인하세요
- OpenAI 서비스 상태: [status.openai.com](https://status.openai.com)

### 이미지가 생성되는데 저장이 안 돼요

- [15-storage](../15-storage/) 문서를 따라 Supabase Storage 설정이 됐는지 확인
- `ai-generated` 버킷이 존재하는지 확인
- RLS 정책이 설정됐는지 확인

### 영상 생성이 안 돼요

- `FAL_API_KEY`가 `.env.local`에 있는지 확인
- FAL 계정에 크레딧이 있는지 확인
- 영상 생성은 1~2분 정도 걸릴 수 있어요 (인내심!)

### 비용이 걱정돼요

- OpenAI에서 **Usage limits**를 설정할 수 있어요
- [platform.openai.com/settings/organization/limits](https://platform.openai.com/settings/organization/limits)에서 월별 한도 설정
- 개발 중에는 `gpt-4o-mini`로 바꾸면 비용을 10분의 1로 줄일 수 있어요

## AI 기능 스킵하기

AI 기능이 필요 없다면:
- `OPENAI_API_KEY`를 설정하지 않으면 돼요
- AI 페이지에 접속하면 "API 키를 설정해주세요" 안내가 나와요
- 앱의 다른 기능(로그인, 결제, 랜딩페이지 등)은 정상 동작해요

AI 메뉴 자체를 숨기고 싶다면 Claude Code에게:
```
"사이드바에서 AI 메뉴 숨겨줘"
```
